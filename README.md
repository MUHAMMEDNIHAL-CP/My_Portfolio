# 🌐 Muhammed Nihal — Developer Portfolio

A modern full-stack developer portfolio website built with React, Vite, and Tailwind CSS. This portfolio showcases projects, skills, experience, and contact information through a premium responsive UI with smooth animations and modern design.

---

# 🚀 Features

* Modern Dark UI
* Responsive Design
* Animated Hero Section
* Skills Showcase
* Projects Section
* Contact Form
* Framer Motion Animations
* Particle Background Effects
* Clean Component Architecture
